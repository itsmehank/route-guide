## 0. 한 줄 요약

기능 자체는 탄탄하다. 진입 직전 로드뷰, 근거 기반 비교표, 공공데이터 위험 지점이 다 있다. 문제는 세 가지다.

1. **같은 정보가 서너 번 반복된다.** 카드 → 상세 헤더 → 말풍선 → 비교표. 게다가 경로 1과 3이 실제로 똑같은 경로다.
2. **지도가 주인공이 아니다.** 사이드바와 패널이 지도를 덮고, 교통량 레이어가 경로 색과 섞인다.
3. **반응형이 전혀 없다.** `@media`가 0개라서 390px에서는 지도가 78px 남는다.

정리하면 "핵심만 남기고, 지도를 넓히고, 상태 피드백을 붙이는" 방향이다.

## 1. 핵심 기능 정의 (사용자가 하려는 일, 우선순위 순)

| 순위 | 사용자 목표 | 지금 화면에서 담당하는 곳 | 비고 |
|---|---|---|---|
| 1 | **출발·도착을 넣고 어떤 길로 갈지 고른다** (시간·거리·통행료) | 입력창 + 경로 카드 3개 + 지도 경로선 | 서비스의 입구. 3초 안에 끝나야 한다 |
| 2 | **헷갈리는 분기점을 미리 눈으로 익힌다** (초보 운전자 핵심 가치) | 상세 턴바이턴 → 말풍선 로드뷰(진입 직전 시점, 앞/뒤 이동) | 경쟁 서비스와 차별되는 부분. 가장 공들일 곳 |
| 3 | **이 길이 나에게 편한지 판단 근거를 얻는다** (유턴·합류 횟수, 편의 순위) | 경로 비교 → 비교표 + 아버지의 한마디 | 숫자는 즉시, 서술은 2~3분. 숫자가 먼저 보여야 한다 |
| 4 | **조심할 지점을 출발 전에 안다** (보호구역·사고다발·단속) | 비교 탭의 위험 구간 목록 | 지금은 목록만 있고 **지도에 표시되지 않는다** |
| 5 | 경유지 추가, 출발·도착 바꾸기, 지도 형태 변경 | 입력부 보조 버튼, 지도 컨트롤 | 보조 기능이다. 눈에 덜 띄어도 된다 |

## 4. 사용 흐름 마찰 지점 (시나리오별)

**① 죽전역 → 강남역, 카드 3개 비교·선택**

- 첫 화면에 이미 죽전역→강남역 경로가 그려져 있다(자동 prefill, L1439-1441). 데모로는 좋다. 하지만 실제 사용자는 "이게 내 검색인가?"하고 잠깐 멈춘다. [확인]
- 카드 3개가 모두 `52분`이고 1번과 3번은 내용이 같다. "뭘 비교하라는 거지?"에서 멈춘다. [확인 `d01`]
- 2번을 선택하면 지도에서 경로가 주황(서행)으로 칠해진다. 교통량 레이어의 주황 도로와 섞여 어느 선이 내 경로인지 한 번 더 찾아야 한다. [확인 `d02`]

**② 상세보기 → 단계 클릭 → 로드뷰 앞/뒤**

- 상세가 열리면 카드와 같은 요약이 옆에 한 번 더 나온다. 지도는 화면의 60%로 줄어든다. [확인 `d03`]
- 단계를 누르면 지도가 30m 축척으로 급확대되고, 말풍선 로드뷰가 3~7초 회색으로 있다가 뜬다. [확인 `d04`→`d05`]
- `◀ 뒤로` 두 번 → `분기점 134m 앞`으로 잘 움직이고 노면 화살표가 보인다. 기능 자체는 좋다. 다만 썸네일이 작아 화살표 판독이 힘들다. [확인 `d06`]
- `다음 단계 ›`를 누르면 다시 로딩을 기다린다. [확인 `d07`]
- `⤢ 전체경로 보기`는 잘 작동한다. [확인 `d09`]

**③ 경유지 추가 → 재탐색, 바꾸기, 다시입력**

- 경유지를 고른 순간 아무 일도 일어나지 않는다. 기존 결과가 그대로라서 "적용됐나?" 하고 헷갈린다. `길찾기`를 눌러야 반영된다. [확인 `d11`]
- 재탐색 중에는 카드가 한 줄 문구로 바뀌고, 지도는 이전 경로를 보여준다. [확인]
- ⇅를 누르면 즉시 재탐색된다. 경유지를 고를 때와 규칙이 다르다. 라벨 3개가 판교 부근에서 겹쳐 2번 시간이 가려진다. [확인 `d13`]
- `다시입력` 후에도 상단에 `Directions 15 · 경유지 1`이 남는다. 지도도 이전 위치 그대로다. [확인 `d22`]

**④ 경로 비교 실행 → 대기**

- 버튼이 11.5px 아웃라인 버튼이라 존재감이 약하다. 핵심 기능 3번인데 보조 버튼처럼 보인다. [확인]
- 누르면 440px 빈 패널에 "아버지가 설명글 쓰는 데 2~3분쯤 걸려" 한 줄만 있다. 그 사이 범례가 가려진다. **실측 2분 이상** 동안 진행 표시가 없다. 다른 걸 해도 되는지, 닫으면 취소되는지 알 수 없다. [확인 `d14`]
- 결과가 나오면 비교표에서 동률인데 1번만 파랗게 강조되어 1번이 우세해 보인다. [확인 `d15`]
- 탭 본문이 4,000자라 스크롤이 길다. 위험 구간에서는 어린이보호구역이 줄줄이 나온다. [확인 `d16`, `d17`]
- 위험 지점 `지도`를 누르면 패널이 닫히고 엉뚱한(가까운) 안내 단계 로드뷰가 뜬다. 다시 비교를 열면 맨 위부터 시작한다. [확인 `d18`]

**⑤ 위성지도·교통량 토글, 전체경로**

- 위성 + 교통량 ON에서는 경로가 거의 안 보인다. 교통량을 끄면 그제야 또렷해진다. [확인 `d20` vs `d21`]
- 토글이 우상단(지도 형태)과 좌하단(교통량)에 나뉘어 있어 찾기 번거롭다. [확인]

**⑥ 검색 결과 없음 / 에러**

- 존재하지 않는 장소를 입력하고 Enter를 쳐도 무반응이다. [확인 `d23`]
- 같은 출발·도착은 서버 원문 JSON 에러가 그대로 노출된다. [확인 `d24`]

**모바일 구조 제안** (구조적 개선 항목과 연결)

- 지도 전체 화면 + **바텀시트 3단**(접힘: 입력 요약 / 중간: 경로 카드 가로 스와이프 / 펼침: 상세·비교)
- 로드뷰는 바텀시트 상단 16:9 영역에 둔다. 지도는 시트 위로 보이는 부분에 분기점이 오도록 padding을 동적으로 계산한다(현재 `mapPad`가 고정 폭이라 이것도 바뀌어야 한다, L1027-1032).
- 입력부는 상단 플로팅 박스로 두고, 경로가 있으면 "죽전역 → 강남역" 한 줄로 접는다.
