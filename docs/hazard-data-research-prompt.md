## 이미 확인한 것 (다시 조사하지 말 것)

- 도로교통공단(TAAS) **사고다발지역** 표준데이터의 분류: 어린이보호구역, 보행어린이, 보행노인,
  자전거, 보행자, 음주운전, 화물차, 이륜차, **결빙**, 법규위반, 지자체별, 연휴기간.
  필드: 사고지역관리번호, 사고연도, 사고유형구분, 위치코드, 시도시군구, 위치명, 사고건수,
  사상자수, 사망자수, 중상자수, 경상자수, 부상신고자수, **위도, 경도, 사고다발지역폴리곤정보**.
  → **야간 분류는 없다.**
- NCP Directions 응답에 차선·조명·노면 정보 없음.

## 조사 대상과 각각에 대해 반드시 답할 것

각 데이터셋마다: (1) 제공 형태(REST API / 파일 다운로드), (2) 정확한 엔드포인트 또는 파일명,
(3) 좌표 필드명과 **좌표계**(WGS84 경위도인지, TM/UTM-K 인지 — 실제 샘플 값 인용),
(4) 인증·신청 절차·일일 쿼터, (5) 갱신 주기, (6) 전국 커버리지 여부, (7) 공식 URL.

### A. 사고다발지역 (TAAS)
- 공공데이터포털 "전국교통사고다발지역표준데이터" vs 도로교통공단 Open API 의 차이
- 폴리곤 필드의 포맷 (WKT? 좌표 배열?)
- 연도별로 따로 받아야 하는가

### B. 무인단속카메라 (과속·신호)
- 경찰청 "안전운전 통합공공데이터" 또는 그에 준하는 소스
- 제한속도 필드 포함 여부, 카메라 종류(과속/신호/구간단속) 구분 필드

### C. 어린이·노인 보호구역
- 구역 경계(폴리곤)인가 지점(중심점)인가
- 제한속도 필드 여부

### D. 결빙·안개 취약구간
- 결빙: TAAS 결빙 사고다발 외에 국토부/도로공사가 별도로 관리하는 "결빙 취약구간" 데이터가 공개되어 있는가
- 안개: 한국도로공사 "안개 잦은 구간" 데이터 공개 여부. 없으면 "없음"으로 명시

### E. 야간 위험 — **새로 조사할 항목**
현재 선택한 데이터에 야간 분류가 없습니다. 아래 중 공개된 것이 있는지 확인:
- 야간 교통사고 통계를 **지점 단위**로 제공하는 데이터 (시군구 집계는 불충분)
- 가로등·도로조명 설치 현황 (지자체 공공데이터)
- 도로공사 "야간 사고 잦은 구간" 류
없으면 "지점 단위 야간 위험 데이터는 공개된 것이 없다"고 명시하세요.

## 답변 방식
- 확인된 사실과 추측을 구분. 불확실하면 "확인 필요".
- 좌표계는 **샘플 값을 인용**해서 판정 (예: `127.0283, 37.4964` 는 WGS84 / `200000, 550000` 대는 TM).
- 마지막에 표: 데이터셋 | 형태 | 좌표계 | 인증 | 갱신 | 커버리지 | 야간/우천 관련성
